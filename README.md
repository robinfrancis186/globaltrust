# globaltrust

Global Trust Challenge website with animated storytelling, programme information, experts, and participation pages.

## Local development

Use a current Node.js version compatible with the package dependencies.

```sh
git clone https://github.com/robinfrancis186/globaltrust.git
cd globaltrust
npm install
npm run dev
```

Run `npm run build` to produce a build. See `package.json` for the available commands.
